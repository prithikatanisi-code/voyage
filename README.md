# BEYOND — Intelligent Tourism Network

GitHub-ready tourism intelligence prototype.

## Run locally
1. Install Node.js.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`

## GitHub Pages
This project includes a GitHub Actions workflow in `.github/workflows/deploy.yml`.
Push the files to the `main` branch, then GitHub will build and deploy the Vite app automatically.
The app uses HashRouter so GitHub Pages navigation works without server-side routing.

## Important
Crowd figures and tourism-board analytics are DEMO DATA. They are not live crowd measurements.
